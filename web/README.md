# Сертификаты — локальная HTML-версия

Откройте **Сертификаты.html** двойным щелчком в Chrome или Edge. Установка, сервер и регистрация не нужны. Для передачи приложения другому человеку достаточно этого одного файла (около 6 МБ).

## Как работать

1. Добавьте фон PNG, JPG или BMP либо используйте встроенный пример.
2. Загрузите Excel/CSV, введите имена вручную или вставьте ссылку на Google Таблицу.
3. Выберите надпись справа. Укажите колонку таблицы или «Общий для всех», настройте размер, жирное начертание (Ж), курсив (К), цвет и ширину блока. По умолчанию используется «Шрифт всех надписей». Для отдельного шрифта включите «Свой шрифт для этой надписи» и выберите его в поле «Шрифт надписи». Надписи можно перемещать мышью; стрелки на выделенном макете перемещают блок на 5 px, Shift + стрелка — на 10 px.
4. Переключайте участников над макетом, чтобы проверить результат.
5. Стрелка вниз у поля «По высоте» опускает надпись, вверх — поднимает. Нажмите «Скачать PDF». Строки с пустым ФИО (включая пробелы) пропускаются; если таких строк все, PDF не создаётся. Можно выгрузить всех участников или только текущего. Экспорт допускает отмену.
6. Сохраните шаблон в JSON перед закрытием приложения. Файл содержит настройки, фон и пользовательский шрифт. Участники в шаблон не входят; таблицу нужно загрузить заново.

## Google Таблицы

Прямая загрузка по ссылке сохранена. Откройте нужную вкладку Google Таблицы и скопируйте URL из адресной строки. Приложение использует `gid` из этой ссылки (при отсутствии — 0). В таблице должен быть включён доступ **«Все, у кого есть ссылка → Читатель»**. По умолчанию строка заголовков определяется автоматически: объединённая первая строка Excel пропускается, если во второй есть названия колонок. Для Google/CSV объединения недоступны, поэтому используется признак разреженной шапки и названий полей во второй строке. Можно указать «Строка заголовков» вручную, например 2. Это также работает для Excel/CSV. После изменения номера загрузите таблицу заново. Строки выше заголовков не попадают в участников; при выборе колонки отображаются буква и название.

Интернет требуется только для Google Таблиц. Чтобы получить изменения, нажмите «Загрузить по ссылке» повторно. Данные запрашиваются непосредственно у Google; стороннего прокси и сервера приложения нет. Закрытые таблицы, требующие входа в аккаунт, не поддерживаются.

Загрузка использует Google Visualization Datasource Protocol. У него типизированные колонки: при смешивании чисел и текста в одной колонке Google может возвращать не все значения. Для таких таблиц используйте единый текстовый формат значений или импортируйте скачанный XLSX. CSV/XLSX импортируются локально без этого ограничения.

## Встроенные пресеты

Встроен шрифт **Roboto Serif**. Добавлены **«Благодарности ШД»**, **«Диплом ДИТЦ»** и **«Диплом ШД»** из папки `F:\Сертификаты\Presets`. Исходные JSON сохранены в `assets/presets/` и автоматически встраиваются при сборке. В двух шаблонах ШД используется системный **Cambria**; если он не установлен на другом ПК, браузер подставит Arial — выберите доступный шрифт и проверьте макет. Фоновое изображение в исходном пресете отсутствовало: его нужно загрузить отдельно. Старые JSON-пресеты Windows-приложения можно открыть кнопкой «Открыть свой шаблон».

Для переноса старых пресетов размер шрифта переведён из пунктов в пиксели (96 DPI). Координатная сетка старого пресета принята 2480 × 3508 px, так как он не хранит размеры фона. При загрузке фона расположение масштабируется. Проверяйте макет: отрисовка браузера отличается от GDI+.

## Форматы и ограничения

- XLSX/XLS: выбор листа, форматированный текст ячеек. Формулы не пересчитываются: читаются сохранённые результаты.
- CSV/TSV: разделители запятая, точка с запятой, табуляция; кавычки и переносы внутри ячейки; UTF-8 и Windows-1251.
- В PDF сохраняются изображения страниц (JPEG 95%). Текст не выделяется. Качество зависит от разрешения фона.
- «По фону»: длинная сторона страницы 297 мм, пропорции сохраняются. В режиме A4 фон вписывается без обрезки, при несовпадении пропорций остаются поля.
- Фоны: до 40 мегапикселей и 10 000 px по стороне. Таблицы: до 10 000 строк и 300 колонок. При больших списках PDF требует больше памяти; удобно экспортировать частями.
- У приложения нет автосохранения. Переносимый JSON-шаблон — основной способ продолжить работу на другом компьютере.

## Для разработчика

Исходники: `src/index.html`, `src/style.css`, `src/app.js`. Библиотеки в `vendor/`, встроенные ресурсы в `assets/`.

Сборка без установки зависимостей:

```text
node build.cjs
```

Она создаёт единый `Сертификаты.html`, включая CSS, JavaScript, библиотеки, шрифт, пресет и уведомления о лицензиях. Не редактируйте собранный HTML отдельно от исходников.

Браузерные проверки: `node test.cjs`. Требуются доступные Node-пакеты `playwright` и `pdf-lib` и Chromium. Путь к установленному браузеру можно передать переменной `BROWSER_EXECUTABLE`; пакетам — стандартной `NODE_PATH`.

`node test-google-live.cjs` — отдельная сетевая проверка на публичной таблице из документации Google. Основные тесты используют контролируемый ответ Google и проверяют локальное открытие с отключённой сетью.

## Публикация сайта

Workflow **Publish Certif to GitHub Pages** публикует сайт при изменениях в `web/` в ветке `master`. Его также можно запустить вручную во вкладке Actions.

Перед первой публикацией откройте **Settings → Pages → Build and deployment → Source** в репозитории GitHub и выберите **GitHub Actions**.

Адрес после успешной публикации: https://grooofy.github.io/Certif/

Для обновления измените исходники в `web/`, создайте коммит и выполните `git push origin master`. Публикуется только собранное приложение как `index.html`.
